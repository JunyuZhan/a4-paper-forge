## A4 纸样工坊（静态站，部署到 Vercel）
- 需求：数百种 A4 打印纸版式（书法/拼音/田字格/方格/坐标/康奈尔等），颜色与格子数量可选，一键打印，按规律分类。
- 实现：纯静态站（index.html + css/style.css + js/{data,paper,app}.js）。
  - `paper.js`：参数化 SVG 渲染器，viewBox 0 0 210 297（mm），25 个版式函数，支持 color / cell / thumb。
  - `data.js`：8 大分类 + 26 个家族，按 颜色×格子尺寸 展开为 **406 种** 版式目录（CATALOG）。
  - `app.js`：侧边分类导航、搜索、画廊、颜色/尺寸按钮、预览、一键打印（@media print 仅输出 A4 纸张）、SVG/PNG 下载、随机。
- 部署：已 git 提交并推送到 GitHub 仓库 `JunyuZhan/a4-paper-forge`（公开）。
  - Vercel CLI 未登录且无 token，无法自动化部署；提供 one-click 导入链接由用户在 Vercel 侧完成导入即上线（纯静态，无需构建）。
- 验证：node 语法检查 + 25 渲染器渲染无 NaN/undefined；本地 http.server 各资源均 200。
