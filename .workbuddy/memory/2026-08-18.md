# 2026-08-18

## A4 纸样工坊（静态站，部署到 Vercel）
- 需求：数百种 A4 打印纸版式（书法/拼音/田字格/方格/坐标/康奈尔等），颜色与格子数量可选，一键打印，按规律分类。
- 实现：纯静态站（index.html + css/style.css + js/{data,paper,app}.js）。
  - `paper.js`：参数化 SVG 渲染器，viewBox 0 0 210 297（mm），25 个版式函数，支持 color / cell / thumb。
  - `data.js`：8 大分类 + 26 个家族，按 颜色×格子尺寸 展开为 **406 种** 版式目录（CATALOG）。
  - `app.js`：侧边分类导航、搜索、画廊、颜色/尺寸按钮、预览、一键打印（@media print 仅输出 A4 纸张）、SVG/PNG 下载、随机。
- 部署：已 git 提交并推送到 GitHub 仓库 `JunyuZhan/a4-paper-forge`（公开）。
  - Vercel CLI 未登录且无 token，无法自动化部署；提供 one-click 导入链接由用户在 Vercel 侧完成导入即上线（纯静态，无需构建）。
- 验证：node 语法检查 + 25 渲染器渲染无 NaN/undefined；本地 http.server 各资源均 200。

## 二次核查与修复（用户反馈：没外框 / 分类筛选像没生效）
- 实证核查：406 种全部渲染 0 异常；各分类命中数 hanzi90/pinyin42/grid84/lined56/math42/draft22/special35/journal35；所有家族 type 均有渲染器；无无效 sizeKey/colorKey。
- 结论：**分类筛选逻辑本来就是对的**（state.cat 变化后 renderGallery 真的过滤），用户误判是因为反馈太弱——画廊标题恒为"全部版式"且画廊在下方，点了没看到变化。
- 修复 1（外框）：`paper.js` 新增 `frame` 选项（默认 true），完整预览/打印时绘距边 8mm 细实线外框（颜色随所选线色），缩略图不画保持干净；`app.js` 加 `frameToggle` 复选框可开关；`blank` 加外框后不再光板。
- 修复 2（筛选反馈）：画廊标题动态显示当前分类（如"✍️ 汉字练习"）；点分类后平滑滚动到画廊；`index.html` 加 `galTitle`/`frameToggle` 节点；`style.css` 加 `.switch` 样式。
- 加固打印：重写 @media print，改为隐藏 `.no-print` 并让 `#sheet` 占满 A4（不再用 body* 全隐藏的粗暴写法，避免误伤 SVG 子元素 display）。
- 已 git 提交并推送到 `origin/master`（仓库 JunyuZhan/a4-paper-forge）。

## 三轮核查与修复（外框细节 + 打印空白）
- 用户质疑 3 点：① 外框是否全加/可自定义 → 答：全局「加外框」开关(默认开)，用户决定；② 有外框时框外不应再有内容 → **真 bug**：原网格从 0 满铺到 210，框外溢出线条。`paper.js` 改用 SVG `clipPath` 把内容裁剪到 (8,8,194,281) 框内，框外不再有线条；缩略图仍不加框。③ 一键打印预览看不到内容 → 真问题：旧打印用 `position:fixed` 有空白风险。`style.css` 改为标准可靠方案（隐藏 `.no-print` + `#sheet` 正常流占满 210×297mm + `@page margin:0`）。
- 验证：全量 406 种 frame=true 渲染异常=0；clipPath/裁剪组/外框矩形结构断言全 true；frame=false 与缩略图均无框；语法 OK。已推送 `origin/master`。
